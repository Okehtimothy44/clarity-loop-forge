# LoopForge
A decentralized platform for creating and managing IoT applications on the Stacks blockchain.

## Features
- Create IoT apps with unique identifiers
- Register IoT devices
- Manage device permissions
- Track device data streams
- Handle data validation and verification
- Device activation management
- Event tracking system
- Device verification status

## Security Features
- Owner-based access control
- Device verification system
- Activity tracking through events
- Device deactivation capability

## Smart Contract Functions
### Administrative Functions
- `create-app`: Create a new IoT application
- `verify-device`: Verify a registered device

### Device Management
- `register-device`: Register a new device
- `deactivate-device`: Deactivate an existing device

### Query Functions
- `get-app`: Retrieve app information
- `get-device`: Retrieve device information
- `get-event`: Retrieve event information
